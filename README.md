# 城市末端配送模拟 · 货损认领与赔付复核

- 行业：物流
- 技术栈：Vue3、Vite、TypeScript、Element Plus、Leaflet
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

在订单点位维护的基础上扩展了货损赔付闭环：

- 骑手登记破损类别、凭证编号与申报金额；同一订单存在待复核申请时，后续申请直接阻止。
- 站点当日赔付累计触及上限（默认 2000 元）后，超出部分占用待复核额度（默认 800 元），占用 2 分钟后超时；额度不足时阻止放行，释放超时占用后才能继续申报。
- 复核通过后订单结案；待复核期间可补证，每次补证生成带原因的新版本，旧金额与凭证清单保留在版本历史中；驳回会立即释放该申请占用的额度。
- 认领记录、额度占用与版本关系整体持久化到 localStorage，重载后三者保持一致。

## 代码位置

- `src/data/orders.ts` —— 订单资料：站点订单点位、配送状态流转与种子数据。
- `src/domain/compensation.ts` —— 赔付判断：申报/补证/复核/额度占用的纯函数领域逻辑，不依赖 Vue。
- `src/store/claims.ts` —— 状态与持久化：把订单资料与赔付判断接到一起，写入 localStorage。
- `src/App.vue` —— 页面呈现：申报表单、复核操作、额度占用面板与版本历史展示。
